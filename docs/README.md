# CRM documentation map

- `architecture/`: UI integration, feature parity, and manager-role design notes.
- `operations/`: account and access-operation notes.
- `deployment/`: MySQL, persistence, landing-data, and deployment guides.
- `reference-ui/`: visual reference screenshots only. They are not served in production.

The production database assets remain in the repository root at `database/`; this documentation folder does not contain runtime SQL.
